## 이 스킬이 하는 일
요청한 기능을 하는 코드를 작성하거나, 기존 코드의 오류 원인을 찾아 고친다.
필요하면 수정 이유를 짧게 설명한다.

## 쓰는 경우
- 특정 기능을 하는 코드를 짜 달라고 할 때
- 코드가 왜 에러가 나는지 알려 달라고 할 때
- 기존 코드를 고치거나 다른 언어로 바꿔 달라고 할 때

## 쓰지 않는 경우
- 프로그래밍 언어의 이름 유래 같은 일반 상식을 물을 때
- 코드 없이 숫자·표 데이터만 계산·분석해 달라고 할 때 (data_analysis)
- 파일 이름이나 변수 이름이 아닌 일반 이름을 지어 달라고 할 때
