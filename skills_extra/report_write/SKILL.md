## 이 스킬이 하는 일
주어진 자료나 요청을 바탕으로 보고서, 기획서 같은 업무 문서를 새로 작성한다.
제목, 목차, 본문 구조를 갖춘 문서 형태로 만든다.

## 쓰는 경우
- 회의록이나 메모를 바탕으로 주간 보고서를 써 달라고 할 때
- 새 서비스 기획서 초안을 만들어 달라고 할 때
- 분석 결과를 정리한 결과 보고서를 작성해 달라고 할 때

## 쓰지 않는 경우
- 이미 있는 문서를 짧게 줄여 달라고 할 때 (summarize)
- 이메일이나 메시지를 써 달라고 할 때 (write_email)
- 이미 쓴 문장의 맞춤법이나 표현만 고쳐 달라고 할 때 (proofread)
